# Foto della galleria SCTRUCKS

Carica qui le immagini JPG, JPEG, PNG, WEBP, GIF o AVIF tramite GitHub (Add file → Upload files). La galleria del sito pubblicato le rileva automaticamente attraverso l'API pubblica GitHub, senza modificare HTML o JavaScript. Le immagini sono pubbliche. Usa nomi come `01-cisterna.jpg`, `02-motrice.jpg` per ordinarle. Finché questa cartella non contiene fotografie, il sito mostra le tre immagini originali `img/img1.jpeg`, `img/img2.jpeg`, `img/img3.jpeg`.

Nota: l'elenco automatico usa il ramo predefinito del repository (master) e può essere soggetto ai limiti di disponibilità dell'API GitHub. Durante la revisione del ramo feature le foto aggiunte soltanto a quel ramo non appariranno finché non vengono pubblicate su master.
